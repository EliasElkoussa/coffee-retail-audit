# Al Gahwa Al Arabiya — Digital Growth & UX Audit

Prepared by Elias Elkoussa, 4 November 2026.

- `index.html` — the interactive audit (six pillars, findings labelled Verified / Hypothesis / To verify).
- `demo.html` — concept storefront: home, Arabic coffee category and Al Kaif Coffee product page, with an English / Arabic switch. No orders are taken.

Product photos load from the store's own image server (media.zid.store), so the demo needs an internet connection.

To publish with GitHub Pages: put both files in the root of a repository, then Settings → Pages → deploy from the main branch. The audit opens at the site root.
